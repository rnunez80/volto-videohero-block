# Changelog

All notable changes to `volto-videohero-block` will be documented in this file.

## [0.2.0] - 2026-10-24

### Bug Fixes & Compatibility
- **Volto 19 Compatibility:** Updated `peerDependencies` to support `@plone/volto` 17, 18, and 19 (`>=17.0.0 || >=18.0.0-alpha.0 || >=19.0.0-alpha.0`).
- **Play/Pause Control:** Fixed play/pause control behavior and state styling using CSS transitions.
- **Performance:** Optimized bundle size by removing unused imports and refactoring video asset loading.

## [0.1.3]

### Fixes
- Initial fixes for theme integration and play/pause behavior.
